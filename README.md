## Como rodar localmente

1. Coloque a pasta em:
```text
xampp/htdocs/
```

2. Inicie:
- Apache
- MySQL

3. Rode o SQL:
```text
sql/schema.sql
```

4. Acesse:
```text
http://localhost/onboarding-system/frontend
```
